# 我的工作台

一个 DSH 主面板页：左侧分区导航，右侧内容区。

## 现在能用

- 侧边栏图标、输入框按钮两个入口都能打开这一页。
- 分区切换是真实交互；离开面板再回来停在上次的分区。
- 页头「回到对话」退回对话页。

## 现在不能用

- 工具卡片、对话输入框、快捷入口、待办复选框都只呈现排版，不触发动作。
- 没有持久化：刷新页面回到第一个分区。

## 开发

- 改 `client.js` 后刷新页面即可，不需要重启 DSH；改 `index.js` 需要重启。
- 改完先跑 `node tools/smoke-client.mjs`：浏览器半边的异常会被加载器吞掉，
  不跑就只能看到「点了图标一片空白」。
